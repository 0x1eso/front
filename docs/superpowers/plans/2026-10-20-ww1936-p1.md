# 1936 세계대전 P1 (산업과 연구) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `worldWar1936` 모드에 HOI4식 경제를 넣는다. 주마다 건물 칸·인프라·인구·자원(scenario.json v2), 민간 공장이 짓는 건설 대기열, 경제·무역·징병법과 소비재, 인력 풀, 자원 6종과 육로·근해·진영 무역, 군수 공장의 생산 라인과 효율, 장비 10종 23세대, 연구 칸 2~5개와 기술 46개, 원작 병력을 인력·보병 장비에 묶는 다리와 장비 비축의 전투 보너스, AI 경제, 산업·연구 서랍과 다이얼. 옵션이 꺼진 게임은 비트 단위로 그대로다.

**Architecture:** 경제 상태는 P0 `WorldWar`가 가진 `WwEconomy` 하나(나라별 `CountryEconomy` 배열, 주 건물 `Uint8Array`, 거래 목록)이고 스냅샷은 `WorldWarState.economy`, 화면에는 `GameUpdateType.WwEconomy`로 나간다. 시계 `WorldWarExecution`이 틱마다 `economy.tick()`을 부르고, 하루를 7틱에 나눠 `smallID % 7`인 나라를 처리한다. 규칙의 순수 계산(효율, 건설, 배분, 인력, 연구 속도, 전투 배율)과 데이터 표(장비, 기술, 법, 시작 값)는 engine-lib에 있어 화면도 같은 코드를 쓴다. 명령은 인텐트 하나 `ww_order {order}`이고 `WwOrderExecution`이 갈래 함수로 넘긴다. 기반 Task가 표·규칙·상태·연결·**최종 시그니처의 스텁**을 모두 꽂고, 갈래가 스텁 본문을 채운다.

**Tech Stack:** TypeScript 6, Vitest 4, zod + zbin, Lit + Tailwind 4, Go 1.24 이상(map-generator, P0과 같이 linux/amd64 Go 1.27로 만든다)

**Spec:** `docs/superpowers/specs/2026-10-20-ww1936-p1-industry-design.md` (이 계획과 같은 커밋). 상위 설계는 `docs/superpowers/specs/2026-10-19-world-war-1936-design.md`. spec의 *(내 판단)* 항목은 모두 확정이다. spec 밖의 구현 결정은 아래 "결정 사항"이 정한다.

## 결정 사항 (spec 밖의 구현 결정)

1. **상태의 자리:** `WwEconomy`는 `WorldWar`의 `readonly economy` 필드다. `GameImpl`에 새 필드·스냅샷 키를 더하지 않는다. 해시도 `WorldWar.hash()`가 더한다.
2. **인텐트 하나:** `ww_order {order: WwOrder}`(`IntentSchema` 맨 뒤). `WwOrder`는 `kind`로 나뉜 13종(`build`, `cancel_build`, `move_build`, `set_law`, `add_line`, `change_line`, `set_line_factories`, `remove_line`, `move_line`, `open_trade`, `close_trade`, `research`, `cancel_research`). 실행은 `WwOrderExecution` 하나(`ExecutionRegistry` 이름 `"WwOrder"`). 서버 `IntentAuthorization`은 바꾸지 않는다(기본 허용, 실행이 보낸 사람의 나라에만 적용).
3. **거절 사유:** 명령 함수는 `WwOrderBlock | null`을 돌려준다. 거절은 조용히 무시하고(로그 없음), 화면은 같은 판정 함수로 버튼을 막는다.
4. **업데이트:** `GameUpdateType.WwEconomy`(맨 뒤). `WorldWarExecution.tick`이 P0 업데이트 다음에 `economy.takeData()`를 보낸다. 시작할 때 모든 나라가 "바뀜"이라 첫 틱에 요약이 다 간다. 첫 업데이트 전에는 `PlayerView.wwTroopCap()`이 지금 병력을 돌려준다(spec §14.4의 "화면이 스스로 첫 값을 만든다"를 이것으로 대신한다 — 한 틱 차이).
5. **메시지:** 새 `MessageType`을 만들지 않고 P0의 `MessageType.WORLD_WAR`를 쓴다. 새 키: `events_display.ww1936_research_done {tech}`, `ww1936_built {count}`, `ww1936_trade_closed {sellerTag, resource}`, `ww1936_slot_free`. 모두 해당 나라 플레이어에게만(`displayMessage(..., player.id())`). `tech`, `resource` 매개변수는 키 조각이고 화면 `EventsDisplay`가 `ww1936.tech.<id>`, `ww1936.res.<id>`로 번역한다(Task 7).
6. **원작 병력:** `PlayerLike.wwTroopCap(): number | null`(맨 뒤 멤버). `Config.maxTroops`는 값이 있으면 `max(troops, cap)`, `troopIncreaseRate`는 0. P0 `WorldWar.start()`의 50% 시작 병력 줄을 지우고 `economy.start()`가 시작 군대를 넣는다.
7. **원작 건물:** `normalizeWorldWar1936Config`가 `disabledUnits`에 `City`, `Factory`를 더한다(spec §4.6).
8. **scenario.json 버전:** 스키마가 `version: 1 | 2`를 받고 새 필드는 zod `.default()`(v1 파일은 `cat: "rural"`, `pop: 0`, `infra: 1`, `core: true`, `coastal: false`, 공장 0, 자원 0)로 채운다. 그래서 Task 2가 실제 지도를 다시 만들기 전에도 모든 테스트가 돈다. Task 2가 실제 지도를 v2로 만들고 테스트가 v2임을 확인한다. 테스트 지도는 Task 1이 v2로 만든다.
9. **주 통제:** `WwEconomy.controller[id]` = 하루 공통 처리 때 그 주 승점 타일의 주인 smallID(사람·AI 국가가 아니면 0). 상태로 저장한다(명령이 하루 사이에 읽는다).
10. **하루 결과도 상태:** `CountryEconomy.totals`(합계, 자원 표, 자유 민간 공장, 최대 병력, 훈련 상한, 전투 수치, 칸 수, 전쟁 날수)를 스냅샷에 넣는다. `CountryEconomy.tech`(연구 완료에서 계산한 기술 합)와 나라별 주 목록·나라 이웃은 파생값이라 복원 때 자기 메서드로 다시 만든다(`DERIVED_FIELDS`).
11. **PRNG 없음:** 경제는 무작위를 쓰지 않는다. 동점은 작은 번호.
12. **전투 연결:** `AttackExecution`은 이 모드에서 `withWwCombat(combat, mg.worldWar(), owner, target)`로 배율을 감싸고, 손실을 적용한 바로 뒤에 `ww.economy.noteCombatLoss(smallID, 손실)`을 부른다(양쪽). 연결은 Task 1이, 본문은 Task 5가.
13. **AI:** AI 경제는 `NationExecution`이 아니라 하루 처리 안에서(`(day + smallID) % 10 === 0`인 `PlayerType.Nation`) `aiEconomyTick`이 돈다. 사람 나라에는 돌지 않는다.
14. **무역 상대의 그래프:** 하루 공통 처리가 주 이웃 쌍과 통제국으로 나라 이웃 목록과 나라별 해역 집합을 만든다(`WwEconomy.countryNeighbours`, `countrySeaZones`). 육로 도달은 Task 4가 너비 우선 탐색으로.
15. **모드 고정값:** P1은 모드가 켜진 판을 바꾼다. Task 1이 `tests/ww1936/WorldWarSnapshot.test.ts`의 `WW1936_DIGEST`를 다시 잡고(세 번 같은 값), 그 테스트의 "항복이 하나 이상" 조건이 P1의 느린 병력 때문에 13,000틱에 안 맞으면 반복을 20,000틱으로 늘린다(조건을 지우지 않는다). 그 뒤 갈래가 규칙 본문을 채울 때마다 그 갈래가 같은 방법으로 다시 잡는다(합칠 때 충돌하면 마지막에 합치는 쪽이 다시 잡는다).

## Global Constraints

- **옵션 끔 = 지금과 비트 단위로 같음:** `worldWar1936`이 없거나 거짓이면 `WwEconomy`가 생기지 않고, `wwTroopCap()`이 `null`이라 `Config`·`AttackExecution`이 지금 코드 그대로 돈다. `tests/VanillaDigest.test.ts`의 모든 고정값과 기존 FullGameSnapshot 변형이 그대로 통과해야 한다.
- **결정성:** `packages/engine*`에서 `Math.random`, `Date.now`, `new Date`, 근사 `Math` 함수, 2가 아닌 지수의 `**`를 쓰지 않는다. 경제 숫자는 정수(밀리·bp·천분율)이고 `Math.floor/min/max/ceil`과 정수 사칙만 쓴다. 곱은 2^53 아래가 되도록 단계마다 내린다(Task 1 `EconomyRules`의 순서를 따른다). 전투 배율만 원작 공격처럼 부동소수(같은 IEEE 연산이라 결정적).
- **와이어는 뒤에만 추가:** `IntentSchema` 맨 뒤 `WwOrderIntentSchema`, `GameUpdateType` 맨 뒤 `WwEconomy`, `PlayerLike` 맨 뒤 `wwTroopCap`. `WwOrder`의 `kind` 순서와 모든 enum 배열(`RESOURCE_IDS`, `EQUIPMENT_TYPES`, `WW_TECH_IDS`, 법 사다리, `BUILDING_IDS`, `REGION_CATEGORIES`)은 한 번 정하면 순서를 바꾸지 않는다(zbin·스냅샷이 순서로 저장한다). 새 값은 뒤에.
- **스냅샷:** 새 Execution `WwOrderExecution`은 `snapshot`/`restoreSnapshot`을 갖고 레지스트리에 등록한다. `restoreState`는 필드를 대입하고 자기 파생값 재계산(`rebuildDerived`)만 부른다. 파생 필드는 `tests/util/Snapshot.ts`의 `DERIVED_FIELDS`에 넣는다.
- **패키지 경계:** engine-api(zod/zbin/resources만), engine-lib(+engine-api), engine(+engine-lib). 화면은 engine을 import하지 않는다. 화면과 엔진이 같이 쓰는 계산은 engine-lib에.
- **홈 화면 청크:** 새 HUD 파일은 `src/client/hud/ww1936/`에만, `Main.ts`가 정적으로 import하지 않는다.
- **화면 문구:** 전부 `translateText()`, 키는 `resources/lang/en.json`(키 정렬, `tests/EnJsonSorted.test.ts`)과 `ko.json`에만. Task 8이 두 파일을 가진다. 다른 갈래는 키 이름만 쓴다(Task 8의 키 표).
- **화면 크기와 조작:** §14d 원작 크기, `title` 금지, 호버 전용 정보 금지, 지우기·취소·거래 닫기는 두 번 탭(3초, P0 `TwoTap`), 서랍 폭 `min(50vw, 420px)`.
- **엔진 변경에는 테스트가 따른다:** 실제 게임(`tests/ww1936/util.ts`의 `wwRunner`, 테스트 지도 `ww1936mini`)으로. 목 없음(화면 테스트의 가짜 GameView 예외).
- **파일 소유:** 각 Task는 자기 **Files**만 고친다. 다른 갈래의 것은 **Interfaces**에 적힌 이름만 쓴다.

## Review Focus

1. **하루에 모든 나라가 정확히 한 번 처리된다**(7틱·8틱 날 모두, 준비 1분 동안은 0번, 저장·복원을 하루 가운데서 해도). 테스트: Task 1 `tests/ww1936/EconomyClock.test.ts` "every country runs exactly once a day", "nothing runs during the preparation minute", Task 9 `tests/ww1936/EconomySnapshot.test.ts` "restoring mid-day continues exactly".

5. **무역은 전쟁·통상 금지·길 끊김·여유 부족에서 새것부터 닫힌다.** 테스트: Task 4 `tests/ww1936/Trade.test.ts` 전체.

/** HOI4 allocation: lines in order take what they need (spec §7.3). */
export function allocateResources(
  available: readonly number[],
  lines: readonly LineNeed[],
): Allocation {
  const left = available.slice(0, RESOURCE_COUNT);
  const used = new Array<number>(RESOURCE_COUNT).fill(0);
  const fill: number[] = [];
  for (const line of lines) {
    const per = EQUIPMENT[EQUIP_KEYS[line.key][0]].resources;
    let f = 1000;
    for (let r = 0; r < RESOURCE_COUNT; r++) {
      const need = per[r] * line.factories;
      if (need === 0) continue;
      const give = Math.min(need, Math.max(0, left[r]));
      left[r] -= give;
      used[r] += give;
      f = Math.min(f, Math.floor((give * 1000) / need));
    }
    fill.push(f);
  }
  return { fill, used };
}

export interface TradeGraph {
  atWar(a: number, b: number): boolean;
  sameFaction(a: number, b: number): boolean;
  neighbours(c: number): readonly number[];
  seaZones(c: number): ReadonlySet<number>;
}

/** Same faction, a shared sea zone, or land through countries at peace with the buyer. */
export function tradeRouteOk(g: TradeGraph, buyer: number, seller: number): boolean {
  if (buyer === seller || g.atWar(buyer, seller)) return false;
  if (g.sameFaction(buyer, seller)) return true;
  const zb = g.seaZones(buyer);
  for (const z of g.seaZones(seller)) if (zb.has(z)) return true;
  const seen = new Set<number>([buyer]);
  const queue = [buyer];
  for (let i = 0; i < queue.length; i++) {
    for (const n of g.neighbours(queue[i])) {
      if (seen.has(n)) continue;
      if (n === seller) return true;
      seen.add(n);
      if (!g.atWar(buyer, n)) queue.push(n);
    }
  }
  return false;
}

 * manpower and trade, and the buildings of every land region. Lives in
 * WorldWar; ticks from WorldWarExecution.
 */
export class WwEconomy {
  private countryList: (CountryEconomy | null)[];
  readonly civ: Uint8Array;
  readonly mil: Uint8Array;
  readonly dock: Uint8Array;
  readonly infra: Uint8Array;
  /** smallID controlling each land region (the owner of its VP tile); 0: nobody. */

  private _trades: Trade[] = [];
  private nextTradeId = 1;
  private lastCommonDay = -1;
  // Derived (DERIVED_FIELDS), rebuilt by rebuildDerived().
  private regionsByCountry: number[][] = [];
  private neighbourLists: number[][] = [];
  private seaZoneSets: Set<number>[] = [];
  private dirtyCountries = new Set<number>();
  private dirtyRegions = new Set<number>();

  constructor(
    readonly mg: Game,
    readonly ww: WorldWar,
    readonly scenario: ScenarioIndex,
  ) {
    const regions = scenario.landRegions;
    const size = (regions.length === 0 ? 0 : regions[regions.length - 1].id) + 1;
    this.civ = new Uint8Array(size);
    this.mil = new Uint8Array(size);
    this.dock = new Uint8Array(size);
    this.infra = new Uint8Array(size);
    this.controller = new Uint16Array(size);
    const owners = scenario.ownerByRegion();
    for (const r of regions) {
      this.civ[r.id] = r.civ;
      this.mil[r.id] = r.mil;
      this.dock[r.id] = r.dock;
      this.infra[r.id] = r.infra;
      this.controller[r.id] = owners[r.id];
    }
    this.countryList = [null];
    scenario.countries.forEach((tag, i) => {
      this.countryList.push(new CountryEconomy(i + 1, tag, COUNTRIES[tag].major, startLaws(tag)));
    });
    this.rebuildDerived();

  /** Spec §11: techs, army, stock, manpower, first totals. WorldWar.start calls it once. */
  start(): void {
    for (const ce of this.countries()) {
      const p = this.mg.playerBySmallID(ce.smallID);
      if (!p.isPlayer()) continue;
      let civ = 0;
      let mil = 0;
      for (const id of this.regionsOf(ce.smallID)) {
        civ += this.civ[id];
        mil += this.mil[id];
      }
      for (const t of startTechs(ce.tag, civ)) ce.addTech(t);
      const recruitable = this.recruitableWith(ce.smallID, ce.law().conscriptionPermille);
      const army = startArmy(ce.tag, recruitable);
      ce.stock = startStock(ce.tag, army, civ, mil);
      ce.fieldInfUnits = infEquipmentFor(army);
      ce.fieldInfGenSum = ce.fieldInfUnits;
      ce.manpower = Math.max(0, recruitable - army);
      p.setTroops(army);
      this.refreshTotals(ce, 0, 0);
      ce.totals.troopCap = troopCapOf(army, ce.manpower, ce.infStock());
      updateCombatStats(this, ce, p);
      this.dirtyCountries.add(ce.smallID);
    }
  }

  // ---- Clock (spec §2) ----

  tick(ticks: number): void {
    if (this.ww.inPrep(ticks)) return;
    const day = this.ww.day(ticks);
    if (day !== this.lastCommonDay) {
      this.lastCommonDay = day;
      this.refreshControl();
      validateTrades(this, ticks);
    }
    const k = ticks - dayStartTick(day, this.ww.prepEndTick());
    if (k < 0 || k >= WW_DAY_SPLIT) return;
    for (let id = 1; id < this.countryList.length; id++) {
      if (id % WW_DAY_SPLIT === k) this.stepCountry(id, day, ticks);
    }
  }

  private stepCountry(id: number, day: number, tick: number): void {
    const ce = this.countryList[id];
    if (ce === null || ce === undefined) return;
    const p = this.mg.playerBySmallID(id);
    if (!p.isPlayer() || !p.isAlive() || this.ww.isCapitulated(id)) return;
    this.refreshTotals(ce, day, tick);
    stepManpower(this, ce, p);
    stepProduction(this, ce);
    stepConstruction(this, ce, p);
    stepResearch(this, ce, p, day);
    applyCombatLosses(this, ce, p);
    stepRecruit(this, ce, p);
    updateCombatStats(this, ce, p);
    if (p.type() === PlayerType.Nation && (day + id) % WW_AI_PERIOD_DAYS === 0) {
      aiEconomyTick(this, ce, p, day, tick);
    }
    this.dirtyCountries.add(id);
  }

  /** Spec §4.4–§4.5: controllers from VP tiles, foreign projects dropped. */
  private refreshControl(): void {
    for (const r of this.scenario.landRegions) {
      const owner = this.mg.owner(this.scenario.vpTile(r));
      const c = owner.isPlayer() ? owner.smallID() : 0;
      if (c === this.controller[r.id]) continue;
      this.controller[r.id] = c;
      this.dirtyRegions.add(r.id);
      for (const ce of this.countries()) {
        if (ce.smallID === c) continue;
        const kept = ce.queue.filter((q) => q.region !== r.id);
        if (kept.length !== ce.queue.length) {
          ce.queue = kept;
          this.dirtyCountries.add(ce.smallID);
        }
      }
    }
    this.rebuildDerived();
  }

  /** Sums of the controlled regions, trades, laws (spec §4.3, §6.2, §7). */
  refreshTotals(ce: CountryEconomy, day: number, tick: number): void {
    const t = ce.totals;
    const law = ce.law();
    let civ = 0;
    let mil = 0;
    let dock = 0;
    let recruitable = 0;
    const produced = zeros();
    for (const id of this.regionsOf(ce.smallID)) {
      const r = this.scenario.region(id)!;
      const cp = this.controlPct(id);
      civ += Math.floor((this.civ[id] * cp) / 100);
      mil += Math.floor((this.mil[id] * cp) / 100);
      dock += Math.floor((this.dock[id] * cp) / 100);
      recruitable += recruitableMen(r.pop, this.manpowerPct(id), law.conscriptionPermille, ce.tech.recruitablePct);
      for (let k = 0; k < RESOURCE_COUNT; k++) {
        produced[k] += extraction(r.res[k], this.infra[id], cp, ce.tech.extractionPct);
      }
    }
    const exported = zeros();
    const imported = zeros();
    let paid = 0;
    let received = 0;
    for (const tr of this._trades) {
      if (tr.buyer === ce.smallID) {
        paid += tr.civs;
        imported[tr.res] += tr.civs * WW_TRADE_UNITS_PER_CIV;
      }
      if (tr.seller === ce.smallID) {
        received += tr.civs;
        exported[tr.res] += tr.civs * WW_TRADE_UNITS_PER_CIV;
      }
    }
    t.civ = civ;
    t.mil = mil;
    t.dock = dock;
    t.recruitable = recruitable;
    t.produced = produced;
    t.exported = exported;
    t.imported = imported;
    t.cgMilli = consumerGoodsMilli(civ, mil, law.consumerGoodsPct);
    t.paidCivs = paid;
    t.receivedCivs = received;
    t.freeCivMilli = freeCivMilli(civ, t.cgMilli, paid, received);
    t.trainCap = trainCap(recruitable, ce.tech.trainPct);
    t.slotCount = researchSlotCount(ce.major, civ + mil);
    t.warDays = this.warDays(ce.smallID, tick);
    void day;
  }

  /** Men the controlled regions give under a conscription law (‰). */
  recruitableWith(smallID: number, permille: number): number {
    const ce = this.country(smallID);
    const bonus = ce === null ? 0 : ce.tech.recruitablePct;
    let n = 0;
    for (const id of this.regionsOf(smallID)) {
      n += recruitableMen(this.scenario.region(id)!.pop, this.manpowerPct(id), permille, bonus);
    }
    return n;
  }

  /** Days of the longest war `smallID` is in now; -1 at peace. */
  warDays(smallID: number, tick: number): number {
    const since = this.ww.earliestWarTick(smallID);
    if (since === null) return -1;
    return this.ww.day(tick) - dayIndex(since, this.ww.prepEndTick());
  }

  /** Spec §4.4: someone else holds it and its 1936 owner still fights. */
  isOccupied(region: number): boolean {
    const c = this.controller[region];

    if (c === 0 || c === owner) return false;
    const o = this.mg.playerBySmallID(owner);

  }

  controlPct(region: number): number {
    return this.isOccupied(region) ? 50 : 100;
  }

  manpowerPct(region: number): number {

  addBuilding(region: number, b: BuildingId, n: number): void {

  trades(): readonly Trade[] {

    const [tr] = this._trades.splice(i, 1);

    this.dirtyCountries.add(tr.seller);

  }

  }

  // ---- Screens ----

  takeData(): WwEconomyData | null {
    if (this.dirtyCountries.size === 0 && this.dirtyRegions.size === 0) return null;
    const data: WwEconomyData = { countries: [], details: [], regions: [] };

  hash(): number {
    let h = 29;
    for (const ce of this.countries()) {
      let stock = 0;

      h = (Math.imul(h, 31) + ce.manpower) | 0;

  }

    for (const c of s.countries) {

      ce.laws = { ...c.laws };
      ce.lawCooldownUntil = { ...c.lawCooldownUntil };

      ce.researched = new Set(c.researched);

    this.controller.set(s.controller);

    this.lastCommonDay = s.lastCommonDay;
    this.rebuildDerived();
    // A restored game's screens have seen nothing yet.
    for (const ce of this.countries()) this.dirtyCountries.add(ce.smallID);
  }

  /** Region lists, country graph, sea zones and tech sums (DERIVED_FIELDS). */
  private rebuildDerived(): void {
    const n = this.countryList.length;
    this.regionsByCountry = Array.from({ length: n }, () => []);
    this.seaZoneSets = Array.from({ length: n }, () => new Set<number>());
    for (const r of this.scenario.landRegions) {
      const c = this.controller[r.id];
      if (c <= 0 || c >= n) continue;
      this.regionsByCountry[c].push(r.id);
      for (const z of this.scenario.regionSeaZones(r.id)) this.seaZoneSets[c].add(z);
    }
    const nb = Array.from({ length: n }, () => new Set<number>());
    for (const [a, b] of this.scenario.regionPairs()) {
      const ca = this.controller[a];
      const cb = this.controller[b];
      if (ca === cb || ca === 0 || cb === 0) continue;
      nb[ca].add(cb);
      nb[cb].add(ca);
    }
    this.neighbourLists = nb.map((s) => [...s].sort((x, y) => x - y));
    for (const ce of this.countries()) ce.tech = techTotals(ce.researched);
  }
}

/** Applies one order for `p`'s country; null when it took effect. */
export function applyWwOrder(
  mg: Game,
  econ: WwEconomy,
  p: Player,
  order: WwOrder,
  day: number,
): WwOrderBlock | null {
  const ce = econ.country(p.smallID());
  if (ce === null || !p.isAlive() || econ.ww.isCapitulated(p.smallID())) return "dead";
  let block: WwOrderBlock | null;
  switch (order.kind) {
    case "build":
      block = queueBuild(econ, ce, order.region, order.building, order.count);
      break;
    case "cancel_build":
      block = cancelBuild(econ, ce, order.index);
      break;
    case "move_build":
      block = moveBuild(econ, ce, order.index, order.to);
      break;
    case "set_law":
      block = setLaw(econ, ce, order.law, order.value, day);
      break;
    case "add_line":
      block = addLine(econ, ce, order.equipment, order.gen, order.factories);
      break;
    case "change_line":
      block = changeLine(econ, ce, order.line, order.equipment, order.gen);
      break;
    case "set_line_factories":
      block = setLineFactories(econ, ce, order.line, order.factories);
      break;
    case "remove_line":
      block = removeLine(econ, ce, order.line);
      break;
    case "move_line":
      block = moveLine(econ, ce, order.line, order.to);
      break;
    case "open_trade": {
      if (!mg.hasPlayer(order.seller)) return "no_partner";
      const seller = mg.player(order.seller);
      block = openTrade(econ, ce, seller.smallID(), RESOURCE_IDS.indexOf(order.resource), order.civs);
      break;
    }
    case "close_trade":
      block = closeTrade(econ, ce, order.trade);
      break;
    case "research":
      block = startResearch(econ, ce, order.tech);
      break;
    case "cancel_research":
      block = cancelResearch(econ, ce, order.slot);

import {
  WwCountryDetail,
  WwCountrySummary,
  WwEconomyData,
  WwRegionData,
} from "@openfront/engine-api/ww1936/EconomyTypes";
import { ScenarioIndex } from "@openfront/engine-lib/ww1936/ScenarioIndex";

/** The screens' copy of the economy, merged from WwEconomy updates. */
export class WwEconomyView {
  private summaries = new Map<number, WwCountrySummary>();
  private details = new Map<number, WwCountryDetail>();
  readonly civ: Uint8Array;
  readonly mil: Uint8Array;
  readonly dock: Uint8Array;
  readonly infra: Uint8Array;
  readonly controller: Uint16Array;
  /** Bumped on every merge; screens redraw when it moves. */
  version = 0;

  constructor(readonly scenario: ScenarioIndex) {
    const regions = scenario.landRegions;
    const size = (regions.length === 0 ? 0 : regions[regions.length - 1].id) + 1;
    this.civ = new Uint8Array(size);
    this.mil = new Uint8Array(size);
    this.dock = new Uint8Array(size);
    this.infra = new Uint8Array(size);
    this.controller = new Uint16Array(size);
    const owners = scenario.ownerByRegion();
    for (const r of regions) {
      this.civ[r.id] = r.civ;
      this.mil[r.id] = r.mil;
      this.dock[r.id] = r.dock;
      this.infra[r.id] = r.infra;
      this.controller[r.id] = owners[r.id];
    }
  }

  apply(d: WwEconomyData): void {
    for (const s of d.countries) this.summaries.set(s.smallID, s);
    for (const x of d.details) this.details.set(x.smallID, x);
    for (const r of d.regions) {
      this.civ[r.id] = r.civ;
      this.mil[r.id] = r.mil;
      this.dock[r.id] = r.dock;
      this.infra[r.id] = r.infra;
      this.controller[r.id] = r.controller;
    }
    this.version++;
  }

  summary(smallID: number): WwCountrySummary | null {
    return this.summaries.get(smallID) ?? null;
  }

  detail(smallID: number): WwCountryDetail | null {
    return this.details.get(smallID) ?? null;
  }

  troopCap(smallID: number): number | null {
    return this.summaries.get(smallID)?.troopCap ?? null;
  }

  region(id: number): WwRegionData {
    return {
      id,
      controller: this.controller[id],
      civ: this.civ[id],
      mil: this.mil[id],
      dock: this.dock[id],
      infra: this.infra[id],
    };
  }
}

export function usedSlots(econ: WwEconomy, region: number): number {
  let n = econ.civ[region] + econ.mil[region] + econ.dock[region];
  const ce = econ.country(econ.controllerOf(region));
  if (ce !== null) {
    for (const q of ce.queue) if (q.region === region && q.building !== "infra") n += q.count;
  }
  return n;
}

function queuedInfra(ce: CountryEconomy, region: number): number {
  let n = 0;
  for (const q of ce.queue) if (q.region === region && q.building === "infra") n += q.count;
  return n;
}

export function buildBlock(econ: WwEconomy, ce: CountryEconomy, region: number, building: BuildingId, count: number): WwOrderBlock | null {
  if (!BUILDABLE.includes(building)) return "not_buildable";
  if (econ.scenario.region(region) === undefined || econ.controllerOf(region) !== ce.smallID) return "not_controlled";
  if (ce.queue.length >= WW_MAX_QUEUE) return "queue_full";
  if (building === "infra") {
    return econ.infra[region] + queuedInfra(ce, region) + count > MAX_INFRA ? "infra_max" : null;
  }
  if (econ.isOccupied(region)) return "occupied";
  return usedSlots(econ, region) + count > econ.regionSlots(region, ce.tech.slotPct) ? "no_slots" : null;
}

export function queueBuild(econ: WwEconomy, ce: CountryEconomy, region: number, building: BuildingId, count: number): WwOrderBlock | null {
  const block = buildBlock(econ, ce, region, building, count);
  if (block !== null) return block;
  ce.queue.push({ region, building, count, progress: 0, lastAssigned: 0, lastSpeedPct: 0 });
  return null;
}

export function cancelBuild(econ: WwEconomy, ce: CountryEconomy, index: number): WwOrderBlock | null {
  if (index >= ce.queue.length) return "bad_index";
  ce.queue.splice(index, 1);
  return null;
}

export function moveBuild(econ: WwEconomy, ce: CountryEconomy, index: number, to: number): WwOrderBlock | null {
  if (index >= ce.queue.length || to >= ce.queue.length) return "bad_index";
  const [q] = ce.queue.splice(index, 1);
  ce.queue.splice(to, 0, q);
  return null;
}

function canComplete(econ: WwEconomy, ce: CountryEconomy, q: Project): boolean {
  if (econ.controllerOf(q.region) !== ce.smallID) return false;
  if (q.building === "infra") return econ.infra[q.region] < MAX_INFRA;
  if (econ.isOccupied(q.region)) return false;
  const built = econ.civ[q.region] + econ.mil[q.region] + econ.dock[q.region];
  return built + 1 <= econ.regionSlots(q.region, ce.tech.slotPct);
}

/** Spec §4.3: free civs front first, ≤ 15 each; excess rolls to the entry's next building. */
export function stepConstruction(econ: WwEconomy, ce: CountryEconomy, p: Player): void {
  const law = ce.law();
  const assigned = assignCivs(ce.totals.freeCivMilli, ce.queue.length);
  let built = 0;
  ce.queue.forEach((q, i) => {
    const speed = projectSpeedPct({ building: q.building, infra: econ.infra[q.region], tech: ce.tech, law });
    q.lastAssigned = assigned[i];
    q.lastSpeedPct = speed;
    if (assigned[i] === 0) return;
    q.progress += constructionProgress(assigned[i], speed);
    const cost = BUILDING_COST[q.building] * 1000;
    while (q.count > 0 && q.progress >= cost) {
      if (!canComplete(econ, ce, q)) {
        q.count = 0;
        break;
      }
      econ.addBuilding(q.region, q.building, 1);
      q.count--;
      q.progress -= cost;
      built++;
    }
  });
  ce.queue = ce.queue.filter((q) => q.count > 0);
  if (built > 0 && p.type() === PlayerType.Human) {
    // P0 displayMessage argument order; params { count }.
    econ.mg.displayMessage("events_display.ww1936_built", MessageType.WORLD_WAR, p.id(), undefined, { count: built });
  }
}

export function stepManpower(econ: WwEconomy, ce: CountryEconomy, p: Player): void {
  const ceiling = Math.max(0, ce.totals.recruitable - Math.floor(p.troops()));
  ce.manpower = Math.min(ce.manpower + manpowerRegrowth(ce.totals.recruitable), ceiling);
}

export function stepRecruit(econ: WwEconomy, ce: CountryEconomy, p: Player): void {
  const t = ce.totals;
  const r = recruitToday(ce.manpower, ce.infStock(), t.trainCap);
  if (r > 0) {
    // One rifle per ten men, newest generation first (spec §6.3).
    let need = infEquipmentFor(r);
    for (let gen = EQUIPMENT_GENS.infantry_equipment; gen >= 1 && need > 0; gen--) {
      const k = equipKey("infantry_equipment", gen);
      const take = Math.min(need, ce.stock[k]);
      ce.stock[k] -= take;
      need -= take;
      ce.fieldInfUnits += take;
      ce.fieldInfGenSum += take * gen;
    }
    ce.manpower -= r;
    p.addTroops(r);
  }
  t.recruited = r;
  t.troopCap = troopCapOf(Math.floor(p.troops()), ce.manpower, ce.infStock());
}

export function lawBlock(econ: WwEconomy, ce: CountryEconomy, kind: LawKind, value: LawValue, day: number): WwOrderBlock | null {
  if (!LAW_LADDERS[kind].includes(value)) return "law_kind";
  if (ce.laws[kind] === value) return "law_same";
  if (day < ce.lawCooldownUntil[kind]) return "law_cooldown";
  const warDays = econ.warDays(ce.smallID, econ.mg.ticks());
  return lawConditionMet(value, { day, warDays }) ? null : "law_condition";
}

export function setLaw(econ: WwEconomy, ce: CountryEconomy, kind: LawKind, value: LawValue, day: number): WwOrderBlock | null {
  const block = lawBlock(econ, ce, kind, value, day);
  if (block !== null) return block;
  if (kind === "conscription") {
    const before = econ.recruitableWith(ce.smallID, conscriptionPermille(ce.laws.conscription));
    const after = econ.recruitableWith(ce.smallID, conscriptionPermille(value as ConscriptionLaw));
    ce.manpower = Math.max(0, ce.manpower + after - before);
  }
  (ce.laws as unknown as Record<LawKind, LawValue>)[kind] = value;
  ce.lawCooldownUntil[kind] = day + WW_LAW_COOLDOWN_DAYS;
  return null;
}

export function stepProduction(econ: WwEconomy, ce: CountryEconomy): void {
  const t = ce.totals;
  let avail = t.mil;
  for (const line of ce.lines) {
    const now = Math.min(line.factories, avail);
    avail -= now;
    if (now > line.active) line.effBp = effAfterAdding(line.effBp, line.active, now - line.active);
    line.active = now;
  }
  t.idleMil = avail;
  const available = t.produced.map((v, k) => v - t.exported[k] + t.imported[k]);
  const alloc = allocateResources(available, ce.lines.map((l) => ({ key: l.key, factories: l.active })));
  t.used = alloc.used;
  const outputPct = ce.law().outputPct + ce.tech.outputPct;
  const cap = effCapBp(ce.tech);
  ce.lines.forEach((line, i) => {
    line.fill = alloc.fill[i];
    if (line.active === 0) {
      line.lastOutput = 0;
      return;
    }
    const out = lineOutputMilli(line.active, line.effBp, outputPct, line.fill);
    line.lastOutput = out;
    line.progress += out;
    const [type, gen] = EQUIP_KEYS[line.key];
    const cost = unitCostMilli(type, gen);
    const units = Math.floor(line.progress / cost);
    ce.stock[line.key] += units;
    line.progress -= units * cost;
    line.effBp = efficiencyGrowth(line.effBp, cap);
  });
}

export interface TradeGraph {
  atWar(a: number, b: number): boolean;
  sameFaction(a: number, b: number): boolean;
  neighbours(c: number): readonly number[];
  seaZones(c: number): ReadonlySet<number>;

/** Spec §7.4: same faction, a shared sea zone, or land through countries at peace with the buyer. */
export function tradeRouteOk(g: TradeGraph, buyer: number, seller: number): boolean {
  if (buyer === seller || g.atWar(buyer, seller)) return false;
  if (g.sameFaction(buyer, seller)) return true;
  const zb = g.seaZones(buyer);
  for (const z of g.seaZones(seller)) if (zb.has(z)) return true;
  const seen = new Set<number>([buyer]);
  const queue = [buyer];
  for (let i = 0; i < queue.length; i++) {
    for (const n of g.neighbours(queue[i])) {
      if (seen.has(n)) continue;
      if (n === seller) return true;
      seen.add(n);
      if (!g.atWar(buyer, n)) queue.push(n);
    }
  }
  return false;
}

  for (let i = 0; i < ce.totals.slotCount; i++) if ((ce.slots[i] ?? null) === null) return i;
  return -1;

export function researchBlock(econ: WwEconomy, ce: CountryEconomy, tech: WwTechId): WwOrderBlock | null {
  if (ce.researched.has(tech)) return "researched";
  if (ce.slots.some((s) => s?.tech === tech)) return "in_progress";
  const def = WW_TECHS[tech];
  if (def.prereqs.some((p) => !ce.researched.has(p))) return "prereq";
  if (def.school !== undefined) {
    const open = openSchool([...ce.researched, ...ce.slots.flatMap((s) => (s === null ? [] : [s.tech]))]);
    if (open !== null && open !== def.school) return "doctrine";
  }
  return freeSlot(ce) < 0 ? "no_slot" : null;
}

export function startResearch(econ: WwEconomy, ce: CountryEconomy, tech: WwTechId): WwOrderBlock | null {
  const block = researchBlock(econ, ce, tech);
  if (block !== null) return block;
  const i = freeSlot(ce);
  while (ce.slots.length <= i) ce.slots.push(null);
  ce.slots[i] = { tech, progress: 0 };
  return null;
}

export function cancelResearch(econ: WwEconomy, ce: CountryEconomy, slot: number): WwOrderBlock | null {
  if (slot >= ce.slots.length || ce.slots[slot] === null) return "bad_slot";
  ce.slots[slot] = null;
  return null;
}

export function stepResearch(econ: WwEconomy, ce: CountryEconomy, p: Player, day: number): void {
  const speed = ce.tech.researchPct + ce.law().researchPct;

/** Men in the field: the pool plus troops out in attacks. */
function armyMen(p: Player): number {
  let n = Math.floor(p.troops());
  for (const a of p.outgoingAttacks()) n += Math.floor(a.troops());
  return n;
}

export function applyCombatLosses(econ: WwEconomy, ce: CountryEconomy, p: Player): void {
  const lost = Math.floor(ce.lossMilli / 1000);
  ce.lossMilli = 0;
  if (lost <= 0) return;
  const before = armyMen(p) + lost;
  const fLost = Math.floor((ce.fieldInfUnits * lost) / before);
  const gLost = ce.fieldInfUnits === 0 ? 0 : Math.floor((ce.fieldInfGenSum * fLost) / ce.fieldInfUnits);
  ce.fieldInfUnits -= fLost;
  ce.fieldInfGenSum -= gLost;
  EQUIP_KEYS.forEach(([type], k) => {
    if (type === "infantry_equipment" || EQUIPMENT[type].needPer100k === 0) return;
    ce.stock[k] -= Math.floor((ce.stock[k] * lost * WW_EQUIPMENT_LOSS_SHARE_PCT) / (before * 100));
  });
}

export function updateCombatStats(econ: WwEconomy, ce: CountryEconomy, p: Player): void {
  const men = armyMen(p);
  const avgInf = ce.fieldInfUnits === 0 ? 100 : Math.floor((ce.fieldInfGenSum * 100) / ce.fieldInfUnits);
  const inf = Math.floor(((avgInf - 100) * 10) / 100);
  let att = inf;
  let def = inf;
  let spd = 0;
  for (const type of EQUIPMENT_TYPES) {
    const d = EQUIPMENT[type];
    if (d.needPer100k === 0) continue;
    let units = 0;
    let genSum = 0;
    for (let g = 1; g <= EQUIPMENT_GENS[type]; g++) {
      const n = ce.stock[equipKey(type, g)];
      units += n;
      genSum += n * g;
    }
    if (units === 0) continue;
    const cov = coveragePermille(units, men, d.needPer100k);
    const gen = genBonusPct(Math.floor((genSum * 100) / units));
    const school =
      d.family === "vehicles"
        ? 100 + ce.tech.vehicleBonusPct
        : d.family === "guns" || type === "support_equipment"
          ? 100 + ce.tech.gunBonusPct
          : 100;
    const part = (x: number) => Math.floor((x * cov * gen * school) / 10_000_000);
    att += part(d.bonus[0]);
    def += part(d.bonus[1]);
    spd += part(d.bonus[2]);
  }
  const clamp = (v: number) => Math.max(0, Math.min(200, v));
  ce.totals.attackPct = clamp(att + ce.tech.attackPct);
  ce.totals.defensePct = clamp(def + ce.tech.defensePct);
  ce.totals.speedPct = clamp(spd + ce.tech.speedPct);
}

export function withWwCombat(
  base: Readonly<DomesticCombat>,
  ww: WorldWar | null,
  attacker: Player,
  defender: Player | null,
): Readonly<DomesticCombat> {
  if (ww === null || defender === null) return base;
  const s = wwCombatScales(ww.economy.combatStats(attacker.smallID()), ww.economy.combatStats(defender.smallID()));
  return {
    ...base,
    attackerLoss: base.attackerLoss * s.attackerLoss,
    defenderLoss: base.defenderLoss * s.defenderLoss,
    attackerSpeed: base.attackerSpeed * s.attackerSpeed,
  };
}
